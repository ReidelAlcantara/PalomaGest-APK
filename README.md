## 📲 Instalación del APK

1. **Descarga** el archivo `PalomaGest-v3.5.2.apk` desde [Releases](https://github.com/ReidelAlcantara/PalomaGest-APK/releases/latest)
2. **Abre el archivo** descargado (desde la barra de notificaciones o el gestor de archivos)
3. Si es la primera vez que instalas una app fuera de Play Store, Android te pedirá
   **permitir "instalar apps desconocidas"** para tu navegador o gestor de archivos → actívalo
4. Pulsa **Instalar** y espera unos segundos
5. **Abre PalomaGest** 🕊️

> 💡 **Requisitos**: Android 7.0 (API 24) o superior. No requiere root.

> 🔄 **Actualizaciones**: instala el nuevo APK encima del anterior sin desinstalar
> (mantiene tus datos). La app también te avisará automáticamente de nuevas versiones.

## 🕊️ ¿Qué es PalomaGest?

PalomaGest es la aplicación completa para la gestión de palomares de palomas
mensajeras y deportivas, creada por y para criadores.

### Módulos principales

| Módulo | Funciones |
|--------|-----------|
| 🏠 **Mi Palomar** | Registro completo de palomas con perfil de identidad, genealogía, fotos, bajas y recuperaciones |
| 🐣 **Reproducción** | Cruces, corredores, timeline de eclosión (18 días), anillado, restricciones de edición de pichones |
| 💊 **Tratamientos** | Calendario médico, base de conocimiento de enfermedades, recordatorios de dosis |
| 🎯 **Capturas** | Registro de capturas por palomo seductor con clima, hora y estadísticas |
| 🏆 **Competiciones** | Competiciones globales entre criadores, resultados oficiales y rankings |
| 💰 **Compra Venta** | Finanzas del palomar con balance, mercado común entre usuarios |
| 📊 **Estadísticas** | Gráficos e inteligencia de todo el palomar |
| 💎 **Puntos** | Gana puntos por capturas y competiciones · 500 puntos = 1 año de licencia |
